# CS336 Project Memory Policy

- Use the installed `pi-memory` tools and their documented behavior; do not create or directly edit a parallel repository-local memory store.
- Add both `#cs336` and `[[cs336-assignment1]]` to every durable entry for this repository.
- Store only durable project decisions, preferences, constraints, plans, lessons, and bugs—not assignment solutions.
- Memory maintenance is an organizational action and does not require `bypass-ta`.
- After a mutation, briefly state what was recorded, changed, or removed.
